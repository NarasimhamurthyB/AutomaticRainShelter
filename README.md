# Automatic Rain Shelter for Crops

## Description
Microcontroller-based system to automatically protect crops during rainfall.

## Inputs
- Rain sensor signals

## Outputs
- DC motors to extend/retract the shelter

## Tech Stack
- 8051 Microcontroller
- Arduino IDE
- C++

## Features
- Automatic shelter deployment during rain
- Prototype tested under different weather conditions

## Challenges
- Motor control timing
- Sensor calibration
